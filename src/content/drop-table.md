## 掉落一览表

记载各战斗任务中、**每个格子已确认的掉落物品**。设有多重掉落的格子，若最大掉落数为 n，则记为 `[×n]`（原页记作 `[Mn]`）。

由于是基于实际确认的更新，仍有可能发现新的掉落，敬请留意。

:::info
每个格子设定的掉落率不同，结果可能与预期不符。
体感上的素材别推荐任务，请参阅[自由任务](#/page/free-quest)。
:::

**表的读法**：每个「战斗」占**前列 / 后列两栏**，纵向 5 行对应 5 个站位。
空白格表示该位置无敌人，`[未]` 表示尚未确认掉落。

## 记号说明

| 记号 | 含义 |
| :-- | :-- |
| `[×n]` | 该格设有多重掉落，最大 n 个（原页记作 `[Mn]`） |
| `[未]` / `[未发现]` | 该格尚未确认到掉落 |
| 空白 | 该位置无敌人 |
| **粗体** | 稀有素材 |

> 掉落机制本身（含「静默掉落」等）的说明见[掉落机制说明](#/page/drop)。最新验证数据见[原文掉落表](https://wikiwiki.jp/tamacolle/%E3%83%89%E3%83%AD%E3%83%83%E3%83%97%E8%A1%A8)。
