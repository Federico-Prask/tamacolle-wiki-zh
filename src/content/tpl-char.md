## 地魂角色页模板（キャラテンプレ）

> ※ 若您有更好的设计，请活用「SandBox」并与「编辑板」商量后随时修改。修改本页时，需要同步修改所有使用它的页面，请牢记后再编辑。

### 基本模板

打开本页整体的编辑，复制下述标记以下的内容使用。

```
★★★以下从『TITLE』行开始模板★★★
★TITLE:角色名
```

基本模板结构：属性 / 立绘 / 语音 / 战法 / 羁绊（信赖·一 / 信赖·特）/ 其他（元ネタ·原型 / 小知识 / 评论）

### 属性（ステータス）

```
●●番　[附件]
名字
武器种 / 所属 / 国势 / 节庆日 / 实装 v ('年/月/日)

初始属性：HP ■ / 攻击值 ■ / 力量 ■ / 魂压值 ■ / 技巧 ■ / 命中 ■ / 丰满足 ■ / 速度 ■
擅长地形
拔魂技：拔魂技名 / 效果 / 拔魂速度
资料室说明：●这里填写资料室说明
画师：大地巧太　声优：
```

### 立绘（絵）

立绘一览：通常立绘 / 战斗立绘 / 负伤 / 通常 [附件×3] / 特写 [附件] / 入浴毛巾 [附件]

### 语音（声）

语音一览：

- **Normal**：标题 / 开始 / 触摸（通常 / 股间 / 负伤 / 放置）/ 庄园（通常 / 走光 / 入浴 / 沐浴——此处填写沐浴时语音）/ 购买 / 资料室 / 成就 / 任务(结束) / 声闻 / 再次声闻 / 羁绊 / 界限突破——此处填写界限突破语音 / 单间（入室·通常·股间——各处填写语音内容）
- **Battle**：编成 / 大魂守 / 神妖连结 / 任务开始 / 分岐 / 发现宝藏 / 意外 / 战斗开始 / 普通攻击 / 拔魂技前（通常 / 反击 / 追击 / 剩敌一人 / 队友负伤）/ 拔魂技 / 中弹（通常 / 负伤(衣服破损)）/ MVP / 镇魂

### 战法（戦法）

图标 / 战法 / 解说 / 习得条件

### 羁绊（絆）

**信赖·一**（表 1~3 × A~F）：位置 / 消耗魂玉 / 内容 / 所需素材。例：A-2 | 100 | 开放活动「活动名」 | ??? x5 + xxx的记文 x3 + yy的智识 x3；B-1 | 300 | 地魂的XX+？ | 素材名 x10 + 地域的记文 x3 + 武器种的智识 x3。

**信赖·特**：A-2 | 3000 | 地魂名的Lv上限 +10 | 地魂名之心 x1 + 素材 x10 + xxx的记文 x10 + yy的智识 x10（B-2=4000、C-2=5000 依次类推）。

### 其他（その他）

- **元ネタ·原型**：这里填写原型说明。
- **小知识**：声闻时播放 / 与土地相关的名称。
- **评论**：请填写情报提供·使用感受等。涉及其他角色的话题请去杂谈公告板。※此处粘贴评论公告板。
