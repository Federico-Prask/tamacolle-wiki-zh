## 地魂男儿页面·帮助

### 概要

这里是对地魂各角色页面各类内容的简易解说页。

### 属性（ステータス）

#### 基本数据

- **编号**：可在资料室确认、为每名地魂设定的编号。
- **立绘**：地魂的基本立绘，声闻时最初看到的身姿。
- **名字**：地魂的名字。以资料室为准，并标注注音。
- **武器**：地魂的武器种，即普通攻击的攻击范围。详见「战斗相关」。
- **所属**：地魂的地域所属，按五畿七道分类。
- **国势**：原型土地的富饶程度。因是当时朝廷所定，与现在可能有出入。
- **节庆日**：类似地魂的生日，每名地魂将与自身有渊源的纪念日当作「节庆日」。
- **实装**：实装后自官方公布起、可获取该地魂的版本 & 年月日。

#### 初始属性

- **HP**：初始 HP，随等级上升而增加。（属性相关详情见「解说页面」）
- **力量**：地魂的力量强度，影响攻击值。
- **技巧**：地魂的技艺，影响攻击值、速度、命中。
- **丰满足**：地魂的丰满度，影响魂压值、速度。
- **攻击值**：影响攻击时造成伤害量的数值，每 Lv25 +1。
- **魂压值**：影响魂压胜负结果及被伤害量的数值，每 Lv10 +1。
- **命中**：关系到攻击命中的难易。
- **速度**：关系到战斗时的行动顺序。
- ※ 实际实数以 0.5 为刻度，但本项目以游戏画面上的数值为准。
- **擅长地形**：每名地魂设定的擅长地形。任务各有地形设定，与擅长地形一致时命中率获得加成。

#### 拔魂技

- **拔魂技名**：发动拔魂技时显示的招式名。
- **效果**：拔魂技时的攻击范围及攻击次数，有时会参考平时的武器种。
- **拔魂速度**：CP 的积攒难易度。

#### 其他

- **资料室说明**：可在资料室查看 & 听取的、地魂的自我介绍。基本原文照载。
- **画师**：担当画师。地魂基本由「大地巧太」担当。
- **声优**：担当声优。

### 立绘（絵）

地魂的身姿与服装（CG 差分）汇总项目。点击图片可放大显示。

#### 内容解说

- **通常立绘**：御座所、庄园对话等处可见的基本立绘。所有服装都有，多数角色仅有这一种。
- **战斗立绘**：编成画面或任务时可见的立绘。出战任务即可解锁。
- **负伤**：任务中剩余 HP 低于最大值一半时可见的负伤立绘。负伤状态下归返即可解锁。
- **服装解说**（※服装效果等详情参照「こちら」）：
  - **通常**：作为地魂的基本身姿。声闻即可解锁。
  - **特写（Cut-in）**：发动拔魂技时显示的横长特写。资料室无法查看。
  - **入浴毛巾**：入浴时的身姿，用于庄园汤殿、任务中的入浴场景等。购买入手后解锁。
  - **春夏服**：春～夏耐热的服装，任务时可穿着。购买解锁。
  - **泳装**：最适合玩水的盛夏装扮。〈期间限定〉购买解锁。
  - **秋冬服**：秋～冬耐寒的服装，任务时可穿着。购买解锁。
  - **晴服**：庆祝正月、身着和服正装的装扮。〈期间限定〉购买解锁。
  - **糕点师服**：装点情人节的糕点师装扮。〈期间限定〉购买时以活动素材兑换解锁。
  - **魂茶屋店员服**：梦幻咖啡馆「魂茶屋」的店员装扮。〈期间限定〉购买时以活动素材兑换解锁。
  - **出门私服**：休息日外出时的装扮。购买解锁。
  - **教师服**：愚人节时穿着的装扮。购买解锁。
  - **咖啡店员 / 酒保 / 女仆服**。
  - **节分赤鬼**：节分时穿着的装扮。购买解锁。
  - **浴衣**：很适合夏日祭的装扮。〈期间限定〉购买时以活动素材兑换解锁。
  - **兜裆布**：奉纳相扑用的神圣兜裆布。〈期间限定〉购买解锁。
  - **きぐぱ（玩偶睡衣）**：可爱的 FANBOX 支援返礼，每月更新，实装起一年后加入购买。
  - **圣诞装扮**：庆祝圣诞的服装。〈期间限定〉购买解锁。

### 语音（声）

汇总各处播放的地魂语音，此处记述播放条件。

#### Normal

- **标题**：游戏开始时的标题画面播放。从所持全部地魂中随机（服装也随机）。
- **开始**：在标题画面点击、开始游戏时播放。与上面「标题」为同一名地魂。
- **触摸**：
  - **通常**：御座所画面、小姓时点击显示的地魂播放。随机两种。
  - **股间**：御座所画面、小姓时点击地魂的股间部播放。
  - **负伤**：御座所及单间画面、小姓时点击任务中负伤的地魂播放。
  - **晴服 / 泳装 / 圣诞服装 / 教师服 / 咖啡店员 / 酒保 / 出门私服 / 女仆服**：御座所画面、小姓时点击穿着相应服装的地魂，与通常混在一起随机播放。
  - **放置**：御座所画面、小姓时完全不操作、放置时播放。
- **庄园**：
  - **通常**：庄园画面点击地魂播放。两种。
  - **走光**：庄园画面点击位于厕所 Lv2 小便器、或 Lv3 厕所·汤殿·寝床的地魂播放。两种。
  - **晴服 / 泳装 / 圣诞服装 / 教师服 / 咖啡店员 / 酒保 / 出门私服 / 女仆服**：庄园画面点击穿着相应服装的地魂，与通常混在一起随机播放。
  - **入浴**：汤殿画面对地魂使用「◯◯之汤」时播放。
  - **沐浴**：汤殿画面对拥有入浴毛巾服装的地魂使用「◯◯之汤」并点击时播放。内容略浓，故被隐藏。
- **购买**：小姓时进入购买画面播放。
- **资料室**：在资料室播放。
- **成就**：小姓时进入成就画面播放。
- **任务(结束)**：小姓时进入任务画面、有任一达成时播放。
- **声闻**：声闻时第一次被声闻的地魂台词。〈初回限定，不可重听〉
- **再次声闻**：声闻时已入手地魂被声闻时播放。
- **羁绊**：羁绊画面结下羁绊时播放。〈次数限定，等于已解锁羁绊数〉
- **界限突破**：羁绊画面解放地魂等级上限时播放。〈次数限定，等于已解锁界限突破数〉内容相当浓，故被隐藏。
- **单间**：
  - **入室**：羁绊画面给地魂安排单间、进入该单间时播放。连续进入也仅首次播放；重新开始游戏等会恢复播放。
  - **通常**：羁绊画面给地魂安排单间、点击显示的地魂播放。随机三种。
  - **股间**：羁绊画面给地魂安排单间、点击地魂的股间部播放。
  - **晴服 / 泳装 / 圣诞服装 / 教师服 / 咖啡店员 / 酒保 / 出门私服 / 女仆服**：羁绊画面给地魂安排单间、点击穿着相应服装的地魂时，与通常混在一起随机播放。

#### Battle

- **编成**：部队编成、配置地魂时播放。
- **大魂守**：部队编成、给地魂装备大魂守时播放。
- **神妖连结**：部队编成、给地魂配属妖怪时播放。与妖怪对白前后两种。
- **任务开始**：任务开始时，成为部队长的地魂的语音播放。
- **分岐**：任务中道路分岔时播放。基本由部队长发出，直前是剧情事件时则为相应地魂。
- **发现宝藏**：到达对应格子时，部队内随机一名地魂的语音播放。
- **意外**：到达对应格子时，部队内随机一名地魂的语音播放。
- **战斗开始**：战斗格子时，部队长的语音播放。
- **普通攻击**：地魂轮到自己攻击时播放。随机两种。
- **拔魂技前**：
  - **通常**：地魂轮到自己发动拔魂技、特写时播放（以下到「队友负伤」共通）。通常是在不符合其他条件的情况下播放。
  - **反击**：直前受到敌人攻击的情况下播放。
  - **追击**：直前与其他地魂攻击同一敌人的情况下播放。
  - **剩敌一人**：剩余敌人数量为一的情况下播放。
  - **队友负伤**：队友直前受到伤害、或队友进入镇魂状态退场的情况下播放。
- **拔魂技**：上述特写之后、伴随攻击播放。
- **中弹**：
  - **通常**：受到敌人攻击时播放。随机两种。
  - **负伤(衣服破损)**：因敌人攻击 HP 跌破最大值一半、进入负伤状态时播放。被一击清空时省略。
- **MVP**：战斗结束的结果画面，成为 MVP 的地魂的语音播放。
- **镇魂**：地魂 HP 被敌人攻击清空、进入镇魂状态退场时播放。

### 战法 & 羁绊

#### 概要

汇总地魂成长要素「羁绊」及由此习得的「战法」的项目。

#### 内容解说

- **战法**：
  - **图标**：战法对应的图标。
  - **战法**：战法名称。
  - **解说**：装备该战法时攻击方针的解说。
  - **习得条件**：地魂习得战法的条件。除初期习得外，随羁绊成长逐步习得。
- **羁绊**：
  - **信赖**：羁绊标签「一」中配置地魂能力成长与个人剧情，「特」中配置地魂等级上限突破、特别剧情。
  - **表(1~3, A~F)**：羁绊页面显示的表，用英数表示纵横位置（分岔处的连接略去）。
  - **位置**：对应上表的坐标。
  - **消耗魂玉**：取得该羁绊所需的魂玉量。
  - **内容**：取得该羁绊时的成长与可观看的剧情。
  - **所需素材**：取得该羁绊所需消耗的素材。

### 其他

#### 概要

其他信息。放置外部网站、地魂本身的梗、评论等杂项信息。

#### 解说

- **介绍 PV**：YouTube 官方频道的视频，以影像简单介绍该地魂，部分地魂没有。
- **元ネタ·原型**：对地魂各种要素的介绍·推测。除部分外并非官方发布，是编辑者的推测，请勿全盘相信。
- **声闻时(略)**：声闻地魂时显示的文字群，仅最初固定，其他约随机显示 6 种。
- **小知识**：上面放不下的地魂梗。
- **评论**：关于地魂的留言板，基本任何人都可留言。每名地魂都有单独设置，但有的没人留言。请在不引战范围内随意使用。
