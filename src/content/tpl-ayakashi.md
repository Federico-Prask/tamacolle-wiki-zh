## 妖怪页模板（あやかしテンプレ）

> ※ 若您有更好的设计，请活用「SandBox」并与「编辑板」商量后随时修改。修改本页时，需要同步修改所有使用它的页面，请牢记后再编辑。

### 基本模板

打开本页整体的编辑，复制下述标记以下的内容使用。

```
★★★以下从『TITLE』行开始模板★★★
★TITLE:角色名
```

基本模板结构：属性 / 立绘 / 语音 / 羁绊（信赖·一）/ 其他（元ネタ·原型 / 小知识 / 评论）

### 属性（ステータス）

```
？？番　[附件]
角色名
分类 ● / 实装 v ('年/月/日)

追加属性：HP / 力量 / 技巧 / 命中 / 丰满足 / 速度 / 追加效果
资料室说明：●这里填写资料室说明
画师：　声优：
```

### 立绘（絵）

立绘一览：通常立绘 / 战斗立绘 / 负伤 / 通常 [附件×3]

### 语音（声）

语音一览：

- **Normal**：庄园（通常 / 走光）/ 资料室 / 声闻
- **Battle**：神妖连结 / 战斗开始 / 普通攻击 / 中弹 / 净化

### 羁绊（絆）

**信赖·一**：（还没有可结下的羁绊。）

### 其他（その他）

- **元ネタ·原型**：这里填写原型说明。
- **小知识**：声闻时播放 / 与妖怪相关的名称。
- **评论**：请填写情报提供·使用感受等。涉及其他角色的话题请去杂谈公告板。※此处粘贴评论公告板。
