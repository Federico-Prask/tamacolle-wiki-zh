## 六原职员页模板（ロクハラテンプレ）

> ※ 若您有更好的设计，请活用「SandBox」并与「编辑板」商量后随时修改。修改本页时，需要同步修改所有使用它的页面，请牢记后再编辑。

### 基本模板

打开本页整体的编辑，复制下述标记以下的内容使用。

```
★★★以下从『TITLE』行开始模板★★★
★TITLE:角色名
```

基本模板结构：属性 / 立绘 / 语音 / 羁绊 / 其他（元ネタ·原型 / 小知识 / 评论）

### 属性（ステータス）

```
●番　[附件]
名字
实装日 v ('年/月/日)
所属 / 年龄 / 生日 / 担当曜日
资料室说明：●这里填写资料室说明
画师：　声优：
```

### 立绘（絵）
