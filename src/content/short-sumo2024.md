ここまでの試合中にある用語・ネタ解説
| IKAKU | 両手を挙げて仁王立ちするポーズを指すワード。特にレッサーパンダが行う場合に用いられる。 他の動物でも似た行動はあるが、立ち上がり両手を広げる行動は、相手に対し身体を大きく見せて圧をかける警戒・敵対行動。レッサーパンダの場合、一番の武器は木登りなどで使用する「するどい爪」であるために、高い位置から振り下ろさんとするこの姿勢は、攻撃の前兆でもあったりする。 人間からしたらベリーキュートな姿勢であるが、軽く皮膚が裂かれかねないその「おてて」には要注意なのである。 |
| --- | --- |
| 光る背景の中で 理解し合う 二人 | アニメ『機動戦士ガンダム』でのシーンが元ネタと思われる。 宇宙に適応した新人類「ニュータイプ」は、その高い空間把握力や感応力により、空間の壁を超越し通信機器を介さず思いを伝えられる超能力をもつように。作中、高いニュータイプ能力を持った主人公と少女、二人は戦闘中にも関わらず極彩色の光る空間の中で互いに思いを伝え合えるように…… |
| !? | 『感嘆符疑問符』という割とストレートなもの。驚愕するシーンなどで主に使われる。 マンガなどで単独で用いられる事も多く、吹き出しにこれだけ入れられる場面も多い。特に、1990年代の少年マガジンにおいて特に多く用いられたことで、ファンの間で「マガジンマーク」と称されたほどであった。 |
| 不運 と 踊 っちまったぜ…… | 元ネタはマンガ『 疾風 伝説 特攻 の拓』の１セリフ。 暴走族が主体として描かれるマンガであり、このセリフも(色んな意味で)かなり凄惨なシーンで使われる。 しかし「“事故”る奴は…“不運(ハードラック)”と”踊(ダンス)”っちまったんだよ…」と、何とも印象的すぎるルビの入り具合から、現在に至るまで同作といえばという有名シーン・ミームとなっている。 |
| トリートメントはしているのか？ | 元ネタはマンガ『幽遊白書』の１シーン。 対戦中、知らぬ間に後ろに回り込まれた相手から首筋に両手を添えられつつ「少々髪が傷んでいる。トリートメントはしているか？」と言われるというもの。美形同士のやり取りであるのも合わせ、そのインパクトのある展開や絵面から、同作の名シーン・ミームの一つとして今も残っている。 |
| (お前の苦労をずっと見てたぞ、本当によく頑張ったな？) | (試合前だがここに併記) TikTok等で流れた謎の動画『ゴールドタイガー』が元ネタとなる。 波動を伴う金色の虎のアップが表示され、ほぼ同じ文言で労ってくるというもの。しかし、すぐに不穏な事を言い出しはじめ、画面の2回タップ(=高評価)を促してきたうえ、謎の爆破の後に金運鑑定へと誘導してくる……つまり。迂遠で胡乱な広告動画であった。 しかし、そのインパクトからネットミームの一つとなり擦られていくことに。 |
| あんこ型・ソップ型 | 共に相撲における力士の体型をあらわす言葉。 『あんこ型』は駿河のように胴が丸く肥えた体型。由来は魚の 鮟鱇 からとされる。 『ソップ型』は脂肪が少なく ガリガリ 痩せた体型。石見は結構肉がついているが、比較的には……といった分類か？ 語源はオランダ語のスープであり、鶏ガラが由来となっている。 |
| ●●に一片の悔いもありません | 漫画『北斗の拳』の登場人物、ラオウの最期からとおもわれる。 世紀末の世界を恐怖と暴力で支配していたラオウは、同門の拳法使いである主人公と大激闘の末、破れる事に。拳を高くかかげ「我が生涯に一片の悔いなし!!」と叫び体内の全エネルギーを天に放出。立ったまま大往生を遂げた。濃い作中でも最も印象に残るシーンと言って過言でなく、下手すれば辞世の句としては歴々の武将よりも有名な可能性すらある。また、ラオウは現実の寺院にて葬儀が行われた初のマンガキャラクターともなった。 |
