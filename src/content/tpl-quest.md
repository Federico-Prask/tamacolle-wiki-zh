## 任务页模板（クエストテンプレ）

> ※ 若您有更好的设计，请活用「SandBox」并与「编辑板」商量后随时修改。修改本页时，需要同步修改所有使用它的页面，请牢记后再编辑。

### 基本模板

分别打开各中标题的编辑画面，连同标题一起复制内容。以下为模板。

#### 迷你标题 · 无战斗任务标题

```
初回报酬
星阳石 x10
备注
无战斗章节
```

#### 迷你标题 · 主线战斗任务标题

```
任务情报
任务地 / 任务：任务地内容 / 任务内容
限制Lv / 舞台 / 气候 / 敌倾向 / 初回报酬or达成报酬
XX～XX | 一番目/二番目 | 星阳石 x10
敌编成等详情见 コチラ
```

#### 迷你标题 · 战斗任务标题

```
任务情报
任务地 / 任务 / 限制Lv / 舞台 / 气候 / 敌倾向 / 初回报酬or达成报酬
XX～XX | 一番目/二番目 | 星阳石 x10

掉落道具
取得报酬 / 经验值(全S)
包袱布：■■（小判 x■ · 魂玉 x■ · 地魂：■ · 主：■）
重箱：■■ ■■
说明文：说明本文

・地图 [附件]

●战目（■）
敌配置 / 评价S / 经验值
■ ■ ▲ ■ ■ ■ ■
报酬：■ ■ 小判 x▲ · 魂玉 x▲ ■ ■

★复数战斗时在此插入战斗复制段★
备注
```

#### 战斗复制段

```
↓从下一行复制
●战目（■）
敌配置 / 评价S / 经验值
■ ■ ▲ ■ ■ ■ ■
报酬：■ ■ 小判 x▲ · 魂玉 x▲ ■ ■
★还有战斗时在此插入战斗复制段★（没有时删除本行）
```
