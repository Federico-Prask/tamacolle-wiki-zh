## 本地人页模板（現地人テンプレ）

原 Wiki 新建「本地人（現地人）」页面时使用的模板骨架。

:::note
本页是**原 Wiki 编辑者用的模板**，不含实际角色数据。
中文站的本地人资料请见 [NPC 分类页](#/page/genchijin)。
:::

### 模板结构

原模板是一张纵向表，字段如下：

| 字段 | 填写内容 |
| :-- | :-- |
| 番号 | `●番` |
| 立绘 | 附件图片 |
| 姓名 | `現地人名(假名注音)` |
| 資料室説明 | 游戏内资料室的原文说明 |
| ―追記― | 编辑者补充的内容 |
| 絵 | 画师名 |

### 模板原文骨架

```
### 現地人名

| ●番 |
| --- |
| [附件] | **現地人名(るび)** |
| 資料室説明 |
| ここに内容 |
| ―追記― |
| ここに内容 |

絵：
```
